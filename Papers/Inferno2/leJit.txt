SuperLoader
====================

I hear a lot of talk about encryption and
obfuscation to try and hide a payload in 
memory. Well I had a thought cross my mind,
what if the payload did not exist yet at 
runtime at all. What if it was just some 
"plaintext" that just so happens to be asm
instructions.

Thats where we are heading today.

About a week or so ago I set off to write a 
64 bit assembler. While writing this I needed
a solid way to test my code. Well what is better
for testing my assembled code than running it 
from memory inside the assembler.

Well this gave me an even better idea. Lets store 
our assembly, encrypted, into a buffer so later we 
can assemble it from memory and run it whenever we 
want to. 

One thing i kept in mind while writing this assembler
was to keep all memory loads rip relative. By keeping
everything rip relative, there is 0 issues running the
assembled code in memory.

Lexor
======

Starting out I just used the commandline arguments to 
supply a asm file to assemble. The code ill be providing
does exactly this. One thing to keep in mind is this is 
not a full or finished version. But it will get the job 
done.

Heres a copy of one of my test files so you can make sure 
yours works:

endI:
peb
mov rax, 1
cmp rax, 1
add rax, 1
jz endI
add rax, 1
jmp loop           
add rax, 1
loop:;              
lea rax, [w]
mov rax, [rax+12]
lea rbx, [w]
mov rdi, 111
mov [rbx], rdi
mov rax, [rbx]
ret

m dq 25;
w db "Sleepy"
p dq 25;

END

There are a couple weird things about the assembler that
I thought I should bring up. When using a jmp, the label 
must end with a ';'. Also do not leave any spaces unless 
it is not code. This version does not handle r8-r15 cry 
about it. "peb" is a macro for getting peb into rax.

But, nonetheless, it can and will support full asm programs.
Feel free to upgrade it how you want.

After the file from disk is assembled, its written to a format,
I did PE for my example, and also executed in memory.

Foreign Exchange
=================

Encryption often comes a heavy cost, entropy. Entropy can make an 
encrypted payload stick out like a soar thumb in memory. 

Awhile back I discovered this strange website
named "forgotten languages". Its a pretty weird site 
that has been posting daily for almost 20 years. But, 
if were to take a look at any of these papers, they are 
not real words, but rather a combination of languages 
put together.

If you ended up looking into that rabbit whole you will
see that nothing can be reliably translated 1 for 1 to 
the real text. Leaving assumptions about what It could be
talking about.

Well, this gave me an idea. 

Lets create our own "forgotten language" and assemble it.

I ended up creating a makeshift lexor that turns words that
I made up into assembly instructions.

            sec[0] = line[9];

            if (xorCheck(line) == 1) {

int constructBytes(int Size, char* name) {

    int offset = 0;
    for (int i=0; i < insCount; i++) {

        // C3
        if (ins[i].opcode == 0xC3) {
            code[offset++] = 0xC3;
            continue;
        }

        // peb
        if (ins[i].REX == 0x99) {
            code[offset++] = 0x65;
            code[offset++] = 0x48;
            code[offset++] = 0x8B;
            code[offset++] = 0x04;
            code[offset++] = 0x25;
            code[offset++] = 0x60;
            code[offset++] = 00;
            code[offset++] = 00;
            code[offset++] = 00;
            continue;
        }

        // for cmp
        if (ins[i].opcode == 0x3D) {
            code[offset++] = ins[i].REX;
            code[offset++] = ins[i].opcode;
            code[offset++] = ins[i].imm32[0];
            code[offset++] = ins[i].imm32[1];
            code[offset++] = ins[i].imm32[2];
            code[offset++] = ins[i].imm32[3];
            continue;
        }
       
        // for sub rax, 1 imediates defaults to rax fast path
        if (ins[i].opcode == 0x2D || ins[i].opcode == 0x83) {

            // for not rax registers 0x83 is the opcode
            if (ins[i].opcode == 0x83) {
            code[offset++] = ins[i].REX;
            code[offset++] = ins[i].opcode;
            code[offset++] = ins[i].modRM;
            code[offset++] = ins[i].imm32[0];
            continue; 
            }

            code[offset++] = ins[i].REX;
            code[offset++] = ins[i].opcode;
            code[offset++] = ins[i].imm32[0];
            code[offset++] = ins[i].imm32[1];
            code[offset++] = ins[i].imm32[2];
            code[offset++] = ins[i].imm32[3];
            continue;
        }

        if (ins[i].opcode == 0xE9 || ins[i].opcode == 0xE8) {
            code[offset++] = ins[i].opcode;    
            if (patchJmp != 0) {
            code[offset++] = patchJmp;
            code[offset++] = 00;
            code[offset++] = 00;
            code[offset++] = 00;
            continue;
            }
            code[offset++] = ins[i].imm32[0];  
            code[offset++] = 0xFF;
            code[offset++] = 0xFF;
            code[offset++] = 0xFF;
            continue;
        }

        // skip for 00 data. This includes labels
        if (ins[i].REX == 00 || ins[i].opcode == 00) continue;

        // Writing values and dont write if 0
        if (ins[i].REX != 0) {
        code[offset++] = ins[i].REX;
        }

        // set opcode at next code[offset]
        code[offset++] = ins[i].opcode;

        // tmp jmp 
        if (ins[i].REX == 0x0F) {
            //printf("printing jz\n");
            //printf("%02X %02X %02X %02X\n", ins[i].imm32[0], ins[i].imm32[1], ins[i].imm32[2], ins[i].imm32[3]);
            // dont set if already patched
            if (dontSet == 1) {
            code[offset++] = patchData;
            code[offset++] = ins[i].imm32[1];
            code[offset++] = 00;
            code[offset++] = 00;
            continue;
            }
            code[offset++] = ins[i].imm32[0];
            code[offset++] = 0xFF;
            code[offset++] = 0xFF;
            code[offset++] = 0xFF;
            continue;
        } 

        // if is not call set modRM because of format
        if (ins[i].modRM != 0x2D) {
        code[offset++] = ins[i].modRM;
        }

        // imm32 added writing the imm for cmp
        if (ins[i].imm32[0] != 00) {
        code[offset++] = ins[i].imm32[0];
        // only do if imm is needed
        if (ins[i].opcode != 0x8B) {
        code[offset++] = ins[i].imm32[1];
        code[offset++] = ins[i].imm32[2];
        code[offset++] = ins[i].imm32[3];
        }
        }
    }

    for (int i=0; i < 100; i++) {
        printf("%02X ", code[i]);
    }

    printf("\nBuilding a PE\n");
    BUILDPEFILE(name, Size, code, 0, 0);

    printf("Calling Directly\n");
    unsigned long* old;
    VirtualProtect(code, Size, 0x40, &old);
    ((void(*)())code)(); 
    return 0;
}
